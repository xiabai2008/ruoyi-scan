# Ruoyi-Scan v1.5.1 发布说明

> 发布日期：2026-10-27 ｜ 适用范围：CLI / Web API / Docker / 桌面端
>
> **一句话**：紧急修复 v1.5.0 桌面端「新建扫描」白屏问题，并改进 CLI 首次使用体验。

---

## ⚠️ 重要修复（桌面端用户请立即升级）

- **修复「新建扫描」必现白屏**：v1.5.0 桌面端点击「新建扫描」后，弹窗组件因条件 Hook 调用触发 `React error #310`，整棵界面被卸载成白屏。v1.5.1 已修复，桌面端可正常新建任务。
  - 受影响范围：**仅 v1.5.0 桌面端**（exe / 安装包）；Web 控制台（`http://127.0.0.1:8123`）不受影响。
  - 若你仍在 v1.5.0，可临时使用浏览器打开 Web 控制台提交任务。
- **新增界面错误边界**：即使将来出现未预期的渲染异常，也会显示可读的错误页与「重新加载」入口，而不是整窗白屏。

## 🔧 体验改进

- **CLI 首次使用体验**：修复版本号显示、缺少目标时的报错提示、结论重复输出、插件显示名等问题。

## 📦 依赖与 CI 维护

- 依赖升级：GitHub Actions、CodeQL Action、桌面 npm、Tauri Cargo、pip（requests / setuptools / aiohttp / redis / httpx2 等）。
- 修复已改名插件导致的过期验收基线项，`main` 与 Nightly 门禁恢复全绿。

## 📥 升级方式

- **PyPI / CLI**：`pip install -U ruoyi-scan`（或 `pip install ruoyi-scan==1.5.1`）
- **桌面端**：在 Release 页下载 `ruoyi-scan-desktop.exe`（单文件）或 `Ruoyi-Scan_v1.5.1_x64-setup.exe`（安装版）
- **Docker / Web**：拉取对应新版本镜像或重新部署
- 升级前建议备份自定义配置与插件目录（`~/.ruoyi-scan/`）

## ✅ 验证

- 使用官方 v1.5.0 桌面包 + WebView2 远程调试复现 `React #310`；修复后同一操作路径弹窗完整渲染、无任何异常。
- 全量测试与静态检查通过；依赖升级后桌面构建冒烟验证通过。
