# Ruoyi-Scan v1.5.0 发布说明

> 发布日期：2026-10-12 ｜ 适用范围：CLI / Web API / Docker / 桌面端
>
> **一句话**：一次面向生产环境的质量版本——安全加固、检测误报/漏报大修，并带来全新的"对抗型传输层"。

---

## ⚡ 亮点速览

- 🛡️ **安全**：API 鉴权改为 fail-closed（无效 scope 不再被提升为 admin）；CI 供应链加固；报告下载路径校验；桌面端启用 CSP 并收窄文件读取作用域
- 🎯 **检测质量**：`file_read` 等十余个插件改用强判据/结构化校验；"不可判定"一律返回 `UNKNOWN`，不再静默判 SAFE；多处潜在漏报修复
- 🚀 **新能力**：对抗型传输层（Scrapling 隐身浏览器 + 指纹伪装，可解 CF/JS 挑战），作为 WAF 绕过的引擎级兜底——**可选项，默认关闭**
- 🧩 **稳定性**：口令字典扫描级隔离（并发不串字典）、分布式队列崩溃恢复、批量扫描按目标出报告（修复"只出第一个目标报告"）、多处资源泄漏与竞态修复
- ✅ **验证**：全量测试 0 失败；签名靶场验收 **vuln 23/23 命中、safe 零误报**

---

## ⚠️ 升级须知（行为变更，请先阅读）

1. **API 密钥权限收紧**：scope 写错的密钥（如 `key:raed`）以前会被当作 `admin` 使用，现在按最小权限 **`read`** 处理；非 ASCII 密钥由 500 改为 401。请核对生产部署的 API Key 配置。
2. **判定更严格**：判断依据不足时返回 `UNKNOWN` 而不是 `SAFE`；历史版本中的部分误报（弱特征命中）会消失——这是本版本的改进方向。
3. **分布式模式**：任务队列改为"至少一次"语义（Worker 崩溃后任务会重入队，可能被重复执行一次），请确保扫描任务的幂等预期。
4. 新增能力（对抗型传输层、桌面头像回退等）**默认不影响现有行为**。

## 🆕 新增能力

- **对抗型传输层（可选）**：`--adversarial-transport` 开关 + `pip install "ruoyi-scan[adversarial]"` 依赖组。
  为 JS 挑战型 WAF（Cloudflare Turnstile 等）提供隐身浏览器兜底与传输指纹伪装；未安装依赖时会降级为常规绕过并给出提示，不会静默失败。
- **验收基线看门狗**：新插件漏登记验收基线，在单元测试阶段即暴露（不再依赖夜间验收发现）。
- **新测试覆盖**：口令字典并发隔离、分布式任务租约恢复等。

## 🎯 检测质量（误报与漏报大修）

- **强判据替代弱特征**：`任意文件读取`/`文件读取（路径穿越）` 改用 `/etc/passwd` 行特征；JeecgBoot 系列（默认口令/文件读取/Freemarker SSTI/SQL 注入/JMReport）改为 JSON 结构化校验；Spring Actuator / Spring Boot Admin 结构校验
- **判定收紧**：CORS 通配符降为低危；MinIO / RocketMQ / Swagger / 源码泄露 / TRACE 等通用子串判定收紧；Spring4Shell 空响应体不再视为成功
- **三态铁律**：网络异常、目标不可达、链路跳过节点等不可判定情形统一返回 `UNKNOWN`（不再伪装成 SAFE）
- **漏报修复**：代码生成模块 SSTI 不再依赖靶场专用标记（真实目标可检出）；无鉴权探测改用独立会话（避免被共享会话的登录态污染）；Nacos 链按实际前缀解析
- **数据准确性**：多处 CVE 归属修正、硬编码 Cookie 清理、证据中的口令/凭据打码

## 🔒 安全性

- API：鉴权 fail-closed、报告下载 `task_id` 路径校验、WebSocket 鉴权与订阅竞态加固
- CI/供应链：`github.ref_name` 注入点消除、nuclei 下载 SHA256 校验、Actions 升级（checkout v7 / setup-python v7 / codeql v4 / codecov v7.1.1）
- 桌面端：Tauri CSP 启用（此前为空）、asset 作用域移除 `$HOME/**`
- 插件仓库：签名覆盖整个清单（防止版本被重标记）、私钥权限 0600
- Docker：非 root 用户、固定 UID 1000、构建上下文密钥排除

## 🧱 稳定性、并发与性能

## 📦 安装与升级

- **PyPI**：`pip install -U ruoyi-scan`
- **GitHub Release 附件**：下载 `ruoyi_scan-1.5.0-py3-none-any.whl` 后 `pip install <whl>`；`checksums.txt` 可校验完整性；产物附带 SLSA 构建来源证明（`gh attestation verify`）
