# 🚀 Ruoyi-Scan v2.0.0 发布

> 2.0 的主题是**可信的检测结果 + 可负担的成本**：新增 OAST/Cloud 能力，补齐指纹、WAF、SourceMap 与 context-path 识别，并把默认爆破行为收敛为安全值。

## ✨ 亮点

### 1. 带外验证（OAST）正式接线

- 新增 `--oast`：扫描侧自动启动 HTTP 回调监听和按需 TCP 监听；
- Log4j JNDI、盲 SSRF、盲 XXE 从“猜测”升级为“回调确认”；
- 未启用时 `requires_oast` 插件自动过滤，不产生噪声 UNKNOWN。

### 2. RuoYi-Cloud 能力包

- Gateway `/actuator/gateway/routes` 路由泄露；
- Nacos 控制台默认口令（8080 控制台 / 8848 API）；
- Cloud job/gen 路由别名回退；
- R8 真实靶场验证：Gateway 路由泄露 + Nacos 默认口令 + Actuator 均命中。

### 3. 性能与成本归因

- 无登录页目标自动跳过 brute：R11 类 Spring API 的 `-u` 请求 **7,185 → 927**；
- 插件级 `plugin_metrics`（requests / duration_ms）；
- `request_count` 改为所有会话真实总和，批量报告不再造假。

### 4. 检测缺口修复

- 前端 SourceMap 源码泄露插件（R7 实测 CONFIRMED）；
- 自定义 context-path 指纹（D1 `/portal`）；
- 无签名 WAF 行为识别（R12/R13）；
- Cloud/Plus 指纹与变体优先级；
- 部门树越权空数据判定、代码生成 SSTI 匿名差分。

### 5. 爆破安全默认值（破坏性）

- `--pass-level` 默认 **top100**，完整字典需显式 `full`；
- 账号锁定/429/验证码自动停止，返回 `UNKNOWN(brute_blocked)`。

## ⚠️ 升级前必读

本版本有破坏性变更：默认字典、request_count 口径、报告字段、已删参数。
详见 [1.x → 2.0 迁移说明](https://github.com/xiabai2008/Ruoyi-Scan/blob/main/docs/MIGRATION_2.0.md)。

## 🧪 验证

- 全量 pytest、ruff、mkdocs strict、插件数 SSOT、export/verification matrix 全部通过；
- 32 个真实靶场目标完成回归（R1–R13、C1/C2/C4、C3/C5/D1/A2/Y1）；
- R10/R11 负样本 0 误报；R12/R13 WAF 行为识别通过；
- R11 性能：927 请求 / 8.2s，结果集逐项不变；
- R1/R2 爆破安全：默认 top100 下结果集保持 6/5 CONFIRMED。
