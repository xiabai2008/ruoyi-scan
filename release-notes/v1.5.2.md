# Ruoyi-Scan v1.5.2 发布说明

> 发布日期：2026-10-28 ｜ 适用范围：CLI / Web API / Docker / 桌面端
>
> **一句话**：把「真实生产形态」的判定做诚实——登录墙、空证据 SAFE、批量报告、首用体验全部对齐文档。

---

## ⚠️ 三态判定修复（建议所有用户升级）

- **登录墙识别**：真实 RuoYi 4.7.8 对未认证请求返回 302→/login（跟随后是 200 登录页），不是 401。此前 7 个插件会把「没测到」写成 SAFE。现在统一识别登录墙并降级 UNKNOWN，同时在终端提示用 `--auth-login` / `--auth cookie` 补登录态。
- **统一兜底**：`detect_auth_wall()` + `downgrade_auth_wall_safe()`，明确 404/401/403 的 SAFE 保留。真实 4.7.8 栈复测：16 条假 SAFE → 0。
- **SAFE 必须带证据**：空 evidence 的 SAFE 统一降级 UNKNOWN（MinIO / RocketMQ 等中间件探测此前 SAFE 无证据）。

## 🔧 体验与交付

- **批量扫描每目标独立报告**：汇总 `batch_report.html/csv` + 每目标 `<host_port>_<timestamp>.<ext>`，与 docs 承诺一致；`targets.txt` 支持 `#` 注释。
- **CLI 首用**：`--help` 与 `-h` 等价；无协议目标自动补 `http://`；登录依赖插件不再输出两条矛盾结论。
- **真实栈靶场**：nginx 反代 `$http_host` + `SERVER_FORWARD_HEADERS_STRATEGY=framework`，修复 Shiro 302 丢端口；smoke 验证码探针补 `?type=math`。
- **README / PyPI**：图片改绝对地址（PyPI 可渲染），新增终端与桌面端真实截图；修正退出码、报告命名、OCR 安装、靶场命令等文档口径。

## 📥 升级方式

- **PyPI / CLI**：`pip install -U ruoyi-scan`（或 `pip install ruoyi-scan==1.5.2`）
- **桌面端**：Release 页下载 `ruoyi-scan-desktop.exe` 或 `Ruoyi-Scan_v1.5.2_x64-setup.exe`
- **Docker / Web**：重新构建镜像或部署
