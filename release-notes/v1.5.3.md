# Ruoyi-Scan v1.5.3 发布说明

> 发布日期：2026-10-30 ｜ 适用范围：桌面端 / Web API / CLI
>
> **一句话**：修复桌面端测评发现的全部 P0/P1/P2 —— 重启后历史任务可信、报告不再串号、停止真的能停、目标不可达有反馈、定时任务可见可删。

---

## 🔴 数据可信性（P0，建议所有桌面端用户升级）

- **重启后历史任务可读**：SQLite 事件恢复时统一归一化为 `{type,data,task_id,timestamp}`，终端不再出现 `undefined:`，三态统计与结果明细不再归零；新增 `findings` 表持久化完整结果，事件被 500 条上限截断时仍可从表兜底。
- **报告不再串号**：报告按 `{task_id}.{ext}` 命名，删除对共享 `report.*` 的全局回退；旧任务可在报告中心点“重建报告”，从持久化结果重新生成。
- **重启中断任务不再假装运行**：pending/running 任务恢复为 `INTERRUPTED`，并明确提示“引擎重启，任务已中断”。

## 🛠 核心可靠性（P1）

- **停止/取消生效**：协作式取消信号 + 引擎每插件检查；状态立即置 CANCELLED 并持久化，执行线程在一次 HTTP 超时内退出，新任务可立即执行。
- **目标不可达有反馈**：扫描前 TCP/HTTP 预检，失败直接 FAILED 并显示原因；新增 `/api/system/probe` 与新建扫描“连通性”按钮。
- **非法目标拦截**：仅 http/https，host/端口校验，缺协议自动补 `http://`；API 入口 422。
- **离线不再永久“提交中…”**：所有前端请求有超时与可读错误；离线禁用提交按钮；指纹探测可设服务端超时。
- **定时任务可管理**：UUID job_id、历史 id 可删除、cron 降级显式提示、独立管理页、上一轮未结束跳过、连续 3 次不可达自动暂停；APScheduler 已纳入引擎打包。
- **CVE 计数/筛选修复**：`N/A` 统一归一化为空串，CVE 数量与筛选恢复真实值。
- **报告下载可用**：原生保存对话框 + 写盘 + 定位文件；HTML 支持应用内预览。

## ✨ 体验（P2）

- 结果表行可点击，新增证据 / 复现命令 / 修复建议 / CVE / CVSS / 原始字段详情抽屉
- 任务标签 × 命中区 24px、自动滚动到选中项、关闭选中项后选中相邻任务
- 顶栏“插件”计数与 WS 实时状态徽标；指纹未识别文案；`plugin_fallback` 可读
- 总览搜索真正过滤；“最新发现”按时间倒序；Ctrl+K 聚焦搜索
- SUPPORT 气泡文字可见；主题编辑器与当前主题同步；离线侧边栏/问候语一致
- 资产页统一 `CANCELLED`；漏洞库“用筛选结果扫描”预置插件；新建扫描占位符/模式重置

**R9 真实走查补充修复**：提交后自动选中新任务（修复列表刷新竞态）；旧任务重建报告支持事件回退、兼容旧事件缺失字段并正确格式化扫描时间；目标校验不再把 `abc` 误判为 IPv6；Widgets 浮窗不再遮挡调度表单按钮和报告预览关闭按钮。

## 📥 升级方式

- **桌面端**：Release 页下载 `ruoyi-scan-desktop.exe`（v1.5.3，内含新引擎）
- **PyPI / CLI**：`pip install -U ruoyi-scan`；cron 用户加装 `ruoyi-scan[schedule]`
- **Web API / Docker**：重新构建镜像或部署
