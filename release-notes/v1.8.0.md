# 🚀 ruoyi-scan v1.8 版本发布

> 本次迭代重点：**请求级限速加固 + 攻击面盘点回流 + 时序盲注检测**，配套完整人工验收体系，稳定性与检测能力同步升级。

## ✨ 新增功能

### 1. 请求级限速（`--rate-scope`）

- 新增参数 `--rate-scope`，支持两种模式：
  - `request`（默认）：按 HTTP 请求限速，精准控制发包频率；
  - `plugin`：旧版行为，按插件启动数量限速。
- 重构令牌桶实现，**所有扫描内会话统一共享限速桶**：爬虫 recon 会话、匿名探测会话、
  隔离登录认证会话全部纳入限速管控，消除历史上认证链路、匿名探测绕过限速的问题。
- ⚠️ 这是可见的行为变更：显式使用 `--rate` 时，默认按请求限速会比旧版慢，属设计预期；
  需要旧行为请加 `--rate-scope plugin`。

### 2. 攻击面盘点回流能力

- 爬虫 `--crawl`（及 `--js-extract`）采集到的接口清单注入扫描会话，插件可直接读取盘点结果。
- 新增 `plugins/common/surface_sweep` 盘点插件：逐入口用匿名会话探测，输出端点清单与
  未认证可达状态（登录墙 / 明确拒绝 / 可读业务数据）。
- 安全约束：盘点模块仅输出 recon 信息，**不会直接生成 CONFIRMED 漏洞结论**，避免误报扩散。

### 3. 时序盲注检测插件 `--time-based`

- 新增 `plugins/ruoyi/sql_blind_time`：针对 `/system/dept/list` 的 `params[dataScope]`，
  用 `if(1=1,sleep(3),0)` 与 `if(1=2,sleep(3),0)` 做双向差分，只验证条件是否被服务端求值，
  不做数据提取。
- 基于中位数差分算法判定时间盲注，降低单次网络抖动带来的误判；慢站、抖动、超时分别归到
  SAFE / UNKNOWN，不会把「慢」当成「有洞」。
- 内置时间预算保护，单端点最大耗时可控，防止扫描超时透支。
- 默认关闭，按需开启，适合深度 SQL 注入检测。

## 🧪 配套验收体系（人工卡点）

新增全套靶场验收脚本，作为版本发布强制准入条件，覆盖三类风险场景：

- `acceptance_chaos_timing.py`：chaos 慢站干扰样本，验证不会因为目标响应延迟误报漏洞；
- `acceptance_vuln_positive.py`：带漏洞正样本，验证时序盲注可以正常检出；
- `acceptance_vuln_negative.py`：修复后干净负样本，验证无漏洞环境不误报；
- 一键汇总入口：`scripts/run_all_acceptance.py`，一次执行全套回归。

> ⚠️ 说明：验收脚本为人工回归工具，不接入 CI 流水线，避免拉长自动化测试耗时。
> 本版本发布前已执行并通过全部三类验收（正样本 CONFIRMED / 负样本 SAFE / 慢站 SAFE）。

## 🛠️ 修复与优化

- 修复：`isolated_auth_session` 隔离登录会话无法继承限速桶，导致认证类插件绕过 `--rate` 限制；
- 修复：`SessionManager.anonymous()` 未继承限速参数，匿名探测路径绕过限速；
- 修复：合并后 `session.deadline` 属性重复声明问题；
- 修复：CLI `--help` 面板缺失限速新参数说明；
- 优化：时序检测预算计算逻辑，修正超时预估偏差，防止超出 `--time-budget`。

## 📌 使用示例

```powershell
# 开启时序盲注检测 + 请求级限速
python main.py -u http://target --time-based --rate 10 --rate-scope request

# 版本发布前全套验收回归
python scripts/run_all_acceptance.py
```
