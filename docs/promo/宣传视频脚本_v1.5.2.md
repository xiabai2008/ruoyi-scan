# Ruoyi-Scan 宣传视频脚本（v1.5.2）

> 目标：让第一次接触的人看完就知道「这是什么、怎么用、为什么可信」，并且能照着复现。
> 成片：3 分 40 秒，16:9，1920×1080，30/60fps，中文口播 + 中文字幕。
> 形式：真人不出镜，全程录屏 + 字幕卡 + 少量动效。

---

## 一、视频定位

| 项 | 内容 |
|---|---|
| 一句话卖点 | 通用扫描器告诉你「可能有洞」，Ruoyi-Scan 告诉你「到底有没有」 |
| 核心差异 | 三态判定：CONFIRMED / SAFE / UNKNOWN，每个插件都给结论 |
| 目标观众 | 安全工程师、渗透测试、DevSecOps、安全专业学生 |
| 观看后动作 | 下载 exe 或 `pip install ruoyi-scan`，扫一遍自己的靶场 |
| 情绪线 | 怀疑（又是扫描器）→ 好奇（敢说没有）→ 信服（有报告有证据）→ 行动 |

不要在片子里堆功能清单。观众只记得住三件事：**三态、一条命令、一份能交付的报告**。

## 二、录制前准备（照着做，省一小时返工）

### 2.1 环境

1. 分辨率 1920×1080，系统缩放 100%（125% 会让终端字发虚）。录制前注销重登确保生效。
2. 桌面清空，任务栏自动隐藏，关闭微信/QQ/杀软弹窗。
3. 用 Windows Terminal + PowerShell，字体 Cascadia Mono 16pt，深色背景，窗口最大化。
4. 终端先执行 `chcp 65001`，否则中文输出可能乱码。
5. 浏览器只留一个标签页，缩放 100%，隐藏书签栏。

### 2.2 演示靶场（必须用本地，不要扫公网）

```powershell
# 窗口 A：带洞靶场
$env:LAB_MODE="vuln"; $env:LAB_PORT="8080"; python lab\server.py

# 窗口 B：全修复靶场（用来演示零误报）
$env:LAB_MODE="safe"; $env:LAB_PORT="8081"; python lab\server.py
```

- 只有源码仓库带 `lab/`，pip 包没有。录视频用源码环境。
- 启动后浏览器访问 `http://127.0.0.1:8080/` 确认是若依风格登录页。
- 录制时把这两个窗口放到第二桌面，别让观众看到启动日志。

### 2.3 预热（关键）

正式录之前完整跑一遍：

```powershell
ruoyi-scan -p http://127.0.0.1:8080/ --report .\reports\warmup --no-pause --no-cta
```

原因：桌面端首次启动要释放引擎（3-5 秒），pip 首次运行要加载插件。预热后录出来才顺。

录之前删掉 `reports\` 下所有演示目录，保证报告中心是干净的。

### 2.5 演示参数（决定录制顺不顺）

- 桌面端「口令字典」默认 `full`，对靶场跑 Druid 爆破会明显拖时间，**录制时改成 `top100`**。
- 报告格式默认 `json/html/csv`，保持默认即可；PDF/DOCX/XLSX 依赖后端库，缺库时这一步会报错，别在视频里赌。
- CLI 一律加 `--no-pause --no-cta`：不等待回车、不打印结尾引导，画面干净。
- 演示目标统一用 `127.0.0.1:8080`（带洞）与 `127.0.0.1:8081`（全修复），不要出现任何真实地址。

### 2.4 录屏软件

OBS，60fps，码率 8000kbps，只录窗口 + 鼠标高亮。鼠标移动要慢，点击前停 0.3 秒。

## 四、口播逐字稿（可直接念）

> 语速控制在每分钟 200 字左右，句号处停 0.3 秒。总字数约 640 字，正好 3 分半。

**【0:00-0:08】**
先说结论：大多数扫描器，只会告诉你「这里可能有漏洞」。
（停一拍）
这个工具，敢告诉你「这里没有」。

**【0:08-0:36】**
它叫 Ruoyi-Scan，若依专项漏洞扫描器。
通用扫描器未命中时，报告里什么都不写。你分不清是「没洞」，还是「根本没测」。
Ruoyi-Scan 给每个插件三种结论：
CONFIRMED，确认存在，有回显、有证据；
SAFE，确认不存在，是测过了、被排除了；
UNKNOWN，测不了，网络不通、WAF 拦了、要登录，它绝不冒充安全。
测过了，才敢说 SAFE。这是它和「结果全红」的扫描器最大的区别。

**【0:36-1:20】**
拿到手两种用法。
第一种，双击这个 exe。引擎和 54 个 POC 全部内置，不需要装 Python，不需要联网。
第一次启动三到五秒，之后窗口直接可用。
点新建扫描，填目标，选模式，点开始。
四种模式：综合扫描跑全流程，漏洞检测只跑 POC，目录扫描摸攻击面，登录爆破测弱口令。
第一次用，选综合扫描就行。

**【1:20-2:05】**
扫描过程是实时的，一个插件一行结论，不用等它全跑完。
绿色的「存在」，红色的「不存在」，黄色的「无法判定」。
跑完你看右侧：确认多少、排除多少、待复核多少，一目了然。
不是一堆「疑似」，是逐条结论。

**【2:05-2:30】**
报告中心可以直接下载。
七种格式：HTML、JSON、CSV、PDF、Word、Excel、SARIF。
HTML 这份是给人看的：风险分布、合规映射、每条漏洞的证据、修复建议、复现命令，
还有等保 2.0 和 OWASP 的条款对应。
换句话说，报告本身就是能交出去的交付物，不用再手工整理一遍。

**【2:30-3:10】**
命令行更适合批量和自动化。
装一行：`pip install -U ruoyi-scan`。
最快的一条：`ruoyi-scan -p http://target:8080/`，三秒出结论。
要完整流程就 `-u`，指纹、目录、POC、弱口令一次跑完。
注意一点：只有写了 `--report 目录`，才会生成报告文件，不写只在屏幕上打印。

**【3:10-3:25】**
可信度怎么证明？
左边是带洞靶场，右边是全修复靶场，同一个工具、同一批插件。
右边全是 SAFE，零误报。这条验收每次 CI 都跑，不是嘴上说。

**【3:25-3:45】**
除此之外，批量目标、CI 卡点、Web 控制台、插件开发，文档里都有。
仓库和命令手册放在简介。
最后一句：只扫你有授权的目标。先用本地靶场跑一遍，别拿生产环境练手。

## 六、拍摄与剪辑要点

1. **开头 3 秒决定完播率**：不要放 logo，不要放「大家好」，直接上结论。
2. **每个操作前留 0.5 秒静止**，观众才跟得上。点击后不要立刻切镜头。
3. **切镜头对齐操作节点**，不要卡在日志滚动中间。
4. **终端输出加速**：CLI 完整输出约 20 行，用 1.5 倍速播放，保留首尾。
5. **报告页用缓推（Ken Burns）**，比静态截图有质感；滚动速度控制在 3 秒一屏。
6. **配乐**：低频电子，音量压到 -28dB，口播为主。三态字幕卡处可加一个 whoosh。
7. **重点词加动效**：CONFIRMED / SAFE / UNKNOWN 出现时，对应颜色扫光一次即可，别循环闪。
8. **不要出现**：真实客户 IP、域名、Cookie、Token、个人目录路径（`C:\Users\HZR\...`）。录之前把窗口标题和路径栏检查一遍。
9. **法律声明必须在片中出现至少 3 秒**：「仅限授权测试」。

## 九、录制前已修掉的三处坑（2026-10-28）

1. `docs/quickstart.md` 原来写 `--auth login=ruoyi:admin123`，**这条命令跑不通**：`--auth` 只接受
   `cookie=` / `bearer=` / `header=`。已改成 `--auth-login ruoyi:admin123 --auth-surface`；
   同段落的 `-f targets.txt` 也补上了必须的模式开关（`-p`），否则命令直接报错。
2. `docs/desktop.md` 写「51 POC」，实际 `--plugin-list` 是 **54** 个，已对齐。
3. `--distributed` 原来是死开关（命令静默退出 0），现已接通 master / worker / standalone，
   参数用 `--redis-url`。视频里可以放心演示，命令手册第 12.5 节有完整写法。
